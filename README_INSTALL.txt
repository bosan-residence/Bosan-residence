BOSAN Residence — PWA для телефона

Це вже одна цілісна версія, яку можна встановлювати на домашній екран телефона ПІСЛЯ розміщення на HTTPS-сайті.

Що вже працює:
- головна панель BOSAN;
- Басейн №1: 24 шезлонги, 3 бунгало, тераса;
- Басейн №2: 40 шезлонгів;
- 5 будиночків;
- 3 окремі чани;
- Баня + чан як один комплекс;
- бронювання за датою/часом;
- блокування подвійної броні;
- гість, телефон, кількість гостей;
- сума, передоплата, борг;
- додаткові послуги;
- каса;
- офлайн-кеш;
- іконка BOSAN;
- режим standalone (відкривається як окрема програма).

Щоб поставити на iPhone:
1. Завантажити ці файли на HTTPS-хостинг.
2. Відкрити адресу в Safari.
3. Натиснути Поділитися.
4. Обрати «На початковий екран».
5. На iPhone з’явиться іконка BOSAN.

Важливо:
- зараз дані локальні на конкретному телефоні;
- для спільної роботи власника та адміністратора треба підключити Supabase/Firebase або іншу хмарну базу;
- сам ZIP напряму як iPhone-додаток не встановлюється.
